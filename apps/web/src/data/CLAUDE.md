# apps/web/src/data/

Static Quran data, generated by `scripts/build-quran-data.ts` (or `build-quran-index.ts` for index-only). All files are checked-in JSON; pages-dir is bulky but a deploy concern, not a runtime one (dynamic-imported per page).

## Index

| Path | What | When to read |
|---|---|---|
| `metadata.json` | 114 chapters (`name_simple/arabic`, `pages`, `verses_count`), 30 juzs (`verse_mapping`), `total_pages` (ADR 0002) | Looking up chapter/juz metadata |
| `quran-index.json` | Derived lookup: per-page surah/ayah ranges, per-surah pages + first-ayah-page map, per-juz pages + ayah ranges (ADR 0007) | Range expansion, juz progress, partial-page logic |
| `pages/` | 604 per-page JSON files with lines + words (surah/ayah/position/code_v2) | Rendering a mushaf page (Phase C MushafPage) |
| `quran-data.ts` | Typed loader + helpers: `CHAPTERS`, `JUZS`, `metadata`, `quranIndex`, `chapter()`, `surahsInJuz()`, `juzAyahRange()` | Reading any of the JSON files at runtime — import from here, not the JSON directly |
