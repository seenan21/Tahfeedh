# apps/web/src/features/live-test/

The Phase D witnessed-test flow (DESIGN.md §14.5 / §14.6) plus the read-only recap (ADR 0022). Live tests reached from `/_authed/tests/$testId`; completed tests redirect to `/_authed/tests/$testId/recap`. All errors stream to the server per tap (ADR 0018); the finish endpoint reads them from the DB. During a live test the mushaf overlay always reflects the *current* session — each logged error immediately tints the corresponding word. Per ADR 0053, an enrolled-teacher witness can opt in to also overlay the student's *historical* `error_location_stats` via a "Show historical errors" Switch in the toolbar (default OFF — avoids witness bias).
