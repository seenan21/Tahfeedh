# apps/web/src/mushaf/

Mushaf renderer + juz tracker grid + read-only page-details side panel + the verse-detail tap surface. All components for "the mushaf" surface (CLAUDE.md shorthand) live here. Imported from `_authed.mushaf.tsx` (student self-view) and `_authed.students.$studentId.mushaf.tsx` (teacher-of-student view) — both delegate to `StudentMushafSurface`. No marking UI — status is test-driven per ADR 0015.

## Index

| File | What | When to read |
|---|---|---|
| `StudentMushafSurface.tsx` | The mushaf surface itself — extracted from `_authed.mushaf.tsx` so the teacher route renders the same UX scoped to an enrolled student. Props: `{ studentId, viewerRole: 'self' \| 'teacher', studentName?, onBack? }`. Owns the Reader/Tracker toggle, toolbar, both queries (`memorization_page`, `error_location_stats`), the `VerseDetailModal` mount, and the per-viewer-context localStorage last-page key (ADR 0052) | Touching the mushaf UX (visual or behavioral changes live here, not in the routes); adding a new viewer-context behavior |
| `MushafPage.tsx` | Renders one Madani 15-line page. Dynamic-imports `data/pages/{N}.json`, applies `font-family: 'QPC V2 P{N}'`, RTL container (no `row-reverse`, ADR 0016), per-page font preload, word + verse tap handlers (delegated through one click listener). Accepts `overlays: ErrorLocationStatsRow[]` + `overlayMode: 'none' \| 'heatmap'`; renders intensity-tinted background + count badge per merged marker (ADR 0011) | Rendering a page, tweaking marker rendering, debugging RTL/justification |
| `MushafPage.module.css` | Page shell (max-width ~720px to mimic printed-mushaf proportions), surah-header chip, justified line layout, marker tint + count badge styles, whole-verse band class (ADR 0035) | Tweaking renderer visuals, marker color/badge, or the whole-verse band |
| `getOverlayMarkers.ts` | `getOverlayMarkers(pageNumber, stats, mode, quranIndex)` collapses `error_location_stats` rows to one marker per visual location, max-intensity for color, total-occurrence for badge (5+ collapse). `loggedErrorsToStats` adapter for live-test in-memory rows. `getErrorsAtLocation` helper. Heat intensity uses `occurrence_count / (1 + tests_since_last_occurrence)` (ADRs 0011, 0019, 0046) | Touching overlay computation, heatmap ramp, or wiring overlays in a new surface |
| `MushafGrid.tsx` | Collapsible juz grid: each juz collapses to a strip with a stacked progress bar + counts; tap to expand and see the page cells. Colored by `memorization_page.status` (`in_progress` / `memorized` only — `mastered` removed per ADR 0047). Click any cell → `onPick(pageNumber)` | Touching the tracker view |
| `MushafGrid.module.css` | Accordion item card, stacked progress bar, page-cell grid | Tweaking tracker visuals |
| `PageDetailsPanel.tsx` | Read-only side panel: status badge + memorized timestamp + review freshness + error summary + recent tests. ADR 0015 (no marking UI) | Touching what the reader's side panel shows |
| `PageDetailsPanel.module.css` | Sticky cream panel styling | Tweaking the side panel visuals |
| `VerseDetailModal.tsx` | The tap surface for the mushaf. Opens on any verse tap (ADR 0045 collapsed marker taps + verse-end taps into one). Contents: `VerseStrip` mushaf-style render of the verse, `VerseAudioPlayer`, `VerseBookmarkButton`, then the per-occurrence error history (groups by error_type; "ghost errors" reveal for cleared signatures per ADRs 0023 + 0026 + 0045) | Touching the verse modal contents, the bookmark slot, the ghost-reveal, or extending the modal to a new surface |
| `VerseStrip.tsx` | Per-verse mushaf-style render with marker tints. Uses `WordSpan` internally. Lives inside `VerseDetailModal`. Reuses the QPC V2 page font + RTL handling (ADR 0045) | Touching the per-verse render or the marker overlay inside the modal |
| `WordSpan.tsx` | Extracted single-word span used by `VerseStrip` (and reused if more mushaf-derived renders appear). Encodes the word-tap handler + marker styling | Touching the word render primitive or sharing it with another surface |
| `VerseAudioPlayer.tsx` | Compact Play/Pause + Stop + 0.5×–2× playback-speed pill for a single ayah. Audio from EveryAyah Ḥusary 128kbps CDN (no auth, no proxy). Resets on surah/ayah change; `<audio onError>` falls back to disabled "unavailable" label (ADR 0042) | Touching playback, the speed control, or extending playback to another surface |
| `VerseBookmarkButton.tsx` | Add-bookmark slot inside `VerseDetailModal`. Connected users POST to `/api/qf-user/bookmarks` (routes to per-user `Tahfeedh` collection). Disconnected users see a contextual Connect CTA in the same slot. Replaces the auto-bookmark-on-milestone behavior (ADR 0045) | Touching the bookmark UX, the Connect-CTA copy, or the bookmark write path |
| `MushafRoute.module.css` | Reader-mode toolbar (three-col grid: chapter select · page flipper · controls) + two-column reader layout with the side panel | Tweaking the mushaf toolbar or the reader layout |
