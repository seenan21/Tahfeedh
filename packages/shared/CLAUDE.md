# packages/shared

`@tahfeedh/shared` — types and Zod schemas consumed by both `apps/web` and `apps/server`. No runtime code beyond schema validation.

## Index

| Path | What | When to read |
|---|---|---|
| `src/` | Types + Zod schemas | Adding or changing a cross-app type/schema |
| `package.json` | Workspace package definition | Adding a dependency to the shared package |
| `tsconfig.json` | TS config | Adjusting compile target/options for shared |
